# 原型交互纠正

- 01 上传和解析保留原控件，删除新增进度条。点击解析后，成功回执触发进入02并创建工艺规划；失败或未决状态不创建任务。恢复已有解析仍可显式创建规划。
- 02 使用原型两栏进度区域。结果返回后通过原“查看工艺规划结果”按钮进入详情。
- 详情保留任务共用信息入口、工序标记、参数与资源、补充信息三个页签，并说明下一步。

## 尚未闭环：现场补充字段

当前 `template-plan-v1-integration` 返回没有任务现场字段；Web adapter 的 onsiteMeasurements 为空。原型 Golden v2 的五项字段标为 demo_required/demo_input，不构成真实制造字段契约。Core template provider 对人工反馈仅保留、不会应用；直接提交 feedback 不能证明毛坯/偏置/装夹修改已作用于 CAM。

因此真实页面无字段时显示“待接入”，不隐藏入口、不伪造“已补齐”或待填数量。本改动未接通现场信息填写提交。

后续须由 Core 与模板配置发布字段 ID、作用域、单位、校验、来源、必填规则和提交能力；服务端保存、回读、修订失效与执行参数应用应分别验证。Web 再按这些字段复用现有表单及动态待填计数。已有允许编辑参数继续通过 parameter_patch 提交。
